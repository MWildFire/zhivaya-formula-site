# Живая формула

Простой учебный сайт по химии и биологии для учеников 5–11 классов. Внутри 18 тем по химии и 18 тем по биологии. Каждая тема состоит из урока, теста из пяти вопросов и одного интересного факта.

Сайт открывается без регистрации и не хранит результаты тестов: всё считается в браузере.

**Адрес:** https://mwildfire.github.io/zhivaya-formula-site/

## Что внутри

- `src/content/` — уроки (Markdown), тесты и факты (JSON);
- `src/pages/`, `src/components/`, `src/layouts/` — страницы и вёрстка (Astro);
- `src/scripts/` — небольшие скрипты в браузере: тесты, фильтры, поиск;
- `scripts/` — проверки содержимого, сборки и локальный сервер;
- `tests/` — автоматические тесты логики.

## Сборка и проверка

Нужен Node.js 24 (версия записана в `.nvmrc`).

```bash
npm ci
npm run check    # типы и проверка содержимого
npm test         # тесты логики
npm run build    # сборка в dist/ и проверки собранного сайта
npm run preview  # локальный просмотр собранного сайта
```

Сайт собирается под подпуть `/zhivaya-formula-site/` (см. `src/config/site.ts`).

## Содержание

Тексты, вопросы и факты написаны для этого сайта. Научные положения основаны на открытых учебных и научных источниках; они перечислены в конце каждого урока. Это не рецензия преподавателя: перед использованием в классе материал стоит просмотреть.
